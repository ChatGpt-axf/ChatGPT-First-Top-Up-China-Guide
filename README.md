## 六、新手充值最容易犯的错误

### 1. 一上来就选 Pro

如果只是普通办公和学习，Plus 通常已经可以满足大部分需求。

### 2. 登录错账号

这是充值后找不到会员时非常常见的排查方向。

### 3. 付款后连续下单

订单正在处理时，不要重复购买。

### 4. 不保存订单号

订单号是后续查询最重要的信息之一。

### 5. 把 Plus 和 API 搞混

ChatGPT Plus / Pro 会员和 API 并不是同一种服务。

如果只是使用 ChatGPT 网页或客户端，主要关注 Plus、Pro；如果要把模型接入自己的程序，则需要另外了解 API。
